Tarefas Operacionais

O módulo de Tarefas permite atribuir e acompanhar atividades da equipe, vinculando-as a lotes, equipamentos, insumos ou outros registros do sistema. Inclui checklist de progresso, alertas de prazo e notificações automáticas.

Administrador · Produção · RH

📋 Introdução

Uma Tarefa no ZYMOS é uma atividade operacional pendente que pode ser atribuída a um membro da equipe, ter um prazo, um checklist de passos e referências a outros registros do sistema (lotes, equipamentos, faturas, etc.).

ℹ️
Acesso: O módulo de Tarefas está na barra de navegação lateral, entre BPM e Admin. Rota: /tareas.

O que são itens e referências?

ConceitoFinalidadeExemplo
Item do checklist Uma ação concreta a executar dentro da tarefa. Marcada como concluída passo a passo. Seu progresso determina o % de conclusão. "Limpar fermentador", "Verificar válvulas", "Pesar maltes"
Referência Link de contexto para um registro do sistema que fornece informações sobre a tarefa. Não é concluída — é apenas um link de navegação. Lote IPA-001, Equipamento Fermentador 2, Fatura #345

➕ Criar uma tarefa

Clique no botão Nova Tarefa no topo da lista.

  1. Título — Nome claro da tarefa (obrigatório, máx. 200 caracteres). Ex: "Manutenção preventiva Fermentador 2".
  2. Descrição — Contexto adicional sobre o que precisa ser feito e por quê (opcional).
  3. Atribuído a — Selecione o usuário responsável pela tarefa. Se não selecionar ninguém, fica como "Não atribuído".
  4. Prioridade — Escolha entre Baixa, Média (padrão), Alta ou Urgente.
  5. Prazo — Data limite para concluir a tarefa (opcional). Se vencer sem ser concluída, será destacada em vermelho.
  6. Itens do checklist — Adicione os passos concretos que quem executa a tarefa deve seguir. Consulte a seção "Itens do checklist".
  7. Referências — Vincule a tarefa a registros do sistema para fornecer contexto. Consulte a seção "Referências".
  8. Salvar — Clique em Salvar. Se você atribuiu a tarefa a outra pessoa, ela receberá uma notificação automática.
💡
Não é obrigatório ter itens ou referências. Você pode criar uma tarefa simples apenas com título e responsável.

☑️ Itens do checklist

Os itens são os passos concretos que compõem a tarefa. Cada item pode ser marcado como concluído a partir do detalhe da tarefa, e o sistema calcula automaticamente o progresso.

Como adicionar itens ao criar/editar uma tarefa

  1. Clique em "Adicionar item" — Um novo campo de texto aparece abaixo dos itens existentes.
  2. Escreva a descrição do passo — Ex: "Desconectar o fermentador da linha de gás".
  3. Repita para cada passo adicional.
  4. Para excluir um item, clique no botão × no lado direito do campo.

Prévia do checklist

✓Desconectar o fermentador da linha de gás
✓Limpar válvulas com solução Star San
Verificar juntas e vedações
Reconectar e testar pressão

2 de 4 passos concluídos — 50%

ℹ️
O status da tarefa é atualizado automaticamente conforme o progresso do checklist: 0% → Pendente, 1–99% → Em andamento, 100% → Concluído.

Como adicionar uma referência

  1. Selecione o tipo no seletor dropdown (Lote, Equipamento, Insumo, etc.).
  2. Digite no campo de busca — Após inserir pelo menos 2 caracteres, aparecem sugestões do sistema com correspondências do tipo selecionado.
  3. Selecione o resultado no dropdown — Um chip (etiqueta) é criado com o nome do registro.
  4. Repita para adicionar mais referências. Você pode adicionar várias referências, inclusive do mesmo tipo (ex: dois equipamentos).
  5. Para remover uma referência, clique no × do chip.

👁️ Ver detalhes da tarefa

Clique no título de uma tarefa na lista para abrir seus detalhes. A tela tem duas colunas:

ColunaConteúdo
EsquerdaChecklist interativo — você pode marcar/desmarcar cada item clicando nele.
DireitaInformações gerais: descrição, atribuído a, criado por, prazo, data de criação e lista de referências com links.

No topo do detalhe estão os botões Editar e Excluir (sujeitos a permissões).

📊 Registrar progresso do checklist

No detalhe da tarefa, clique em qualquer item do checklist para marcá-lo como concluído. O sistema atualiza em tempo real sem recarregar a página.

  1. Clique no item — A caixa de seleção fica verde com uma marca ✓ e o texto é riscado.
  2. A barra de progresso é atualizada automaticamente com o novo percentual.
  3. O badge de status muda: Pendente → Em andamento → Concluído, conforme o percentual.
  4. Para desmarcar um item, clique nele novamente — o sistema também permite reverter.
💡
Quando todos os itens forem marcados, o status muda automaticamente para Concluído. Não é necessário alterar manualmente.

🏷️ Status e prioridades

Status das tarefas

StatusSignificadoQuando é atribuído
PendenteNenhum item concluído ainda.Quando a tarefa é criada, ou se todos os itens forem desmarcados.
Em andamentoPelo menos um item concluído, mas não todos.Automaticamente quando o primeiro item é marcado.
ConcluídoTodos os itens concluídos.Automaticamente quando o último item é marcado.
ℹ️
Se a tarefa não tiver itens, o status não muda automaticamente — você pode editá-la e ajustar o status manualmente.

Prioridades

PrioridadeQuando usar
BaixaAtividades de melhoria ou sem urgência de tempo.
MédiaValor padrão. Atividades normais do dia a dia.
AltaImpacta a produção ou tem prazo próximo.
UrgenteRequer atenção imediata. Afeta a qualidade ou segurança do produto.

🔔 Notificações automáticas

O ZYMOS envia notificações no sistema (sino na barra de navegação) em duas situações:

EventoQuem recebeQuando
Tarefa atribuída O usuário atribuído. Ao criar ou editar uma tarefa, se o responsável for diferente do criador. (Não é notificado se você atribuir uma tarefa a si mesmo.)
Tarefa vencida O usuário atribuído. Verificação diária automática: tarefas com prazo vencido ou para hoje/amanhã que não estejam concluídas.
💡
As notificações aparecem como um ponto vermelho no sino da barra de navegação. Clique no sino para ver todas.
📱
Também via WhatsApp Se o administrador configurou contatos WhatsApp em Admin → WhatsApp, os eventos de tarefa atribuída também geram uma mensagem WhatsApp para o contato inscrito no tipo "Tarefa atribuída". Consulte Manual de Administração → Notificações WhatsApp.
