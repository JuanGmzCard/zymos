Operational Tasks

The Tasks module lets you assign and track team activities, linking them to batches, equipment, ingredients, or other system entities. Includes a progress checklist, due date alerts, and automatic notifications.

Administrator · Production · HR

📋 Introduction

A Task in ZYMOS is a pending operational activity that can be assigned to a team member, have a deadline, a checklist of steps, and references to other system records (batches, equipment, invoices, etc.).

ℹ️
Access: The Tasks module is in the side navigation bar, between BPM and Admin. Route: /tareas.

What are items and references?

ConceptPurposeExample
Checklist item A concrete action to execute within the task. Marked as completed step by step. Its progress determines the % completion. "Clean fermenter", "Check valves", "Weigh malts"
Reference Context link to a system record that provides information about the task. Not completed — it is a navigation link. Batch IPA-001, Fermenter 2 equipment, Invoice #345

➕ Create a task

Click the New Task button at the top of the list.

  1. Title — Clear task name (required, max 200 characters). E.g. "Preventive maintenance Fermenter 2".
  2. Description — Additional context about what needs to be done and why (optional).
  3. Assigned to — Select the user responsible for this task. If you don't select anyone, it remains "Unassigned".
  4. Priority — Choose between Low, Medium (default), High, or Urgent.
  5. Due date — Deadline to complete the task (optional). If it expires without being completed, it will be highlighted in red.
  6. Checklist items — Add the concrete steps that whoever executes the task must follow. See the "Checklist items" section.
  7. References — Link the task to system records to provide context. See the "References" section.
  8. Save — Click Save. If you assigned the task to another person, they will receive an automatic notification.
💡
It is not required to have items or references. You can create a simple task with just a title and assignee.

☑️ Checklist items

Items are the concrete steps that make up the task. Each item can be marked as completed from the task detail, and the system automatically calculates progress.

How to add items when creating/editing a task

  1. Click "Add item" — A new text field appears below existing items.
  2. Write the step description — E.g. "Disconnect fermenter from the gas line".
  3. Repeat for each additional step.
  4. To delete an item, click the × button on the right side of the field.

Checklist preview

✓Disconnect fermenter from the gas line
✓Clean valves with Star San solution
Check gaskets and seals
Reconnect and test pressure

2 of 4 steps completed — 50%

ℹ️
The task status updates automatically based on checklist progress: 0% → Pending, 1–99% → In progress, 100% → Completed.

How to add a reference

  1. Select the type in the dropdown selector (Batch, Equipment, Ingredient, etc.).
  2. Type in the search field — After entering at least 2 characters, system suggestions appear with matches of the selected type.
  3. Select the result in the dropdown — A chip (tag) is created with the record name.
  4. Repeat to add more references. You can add multiple references, even of the same type (e.g. two equipment items).
  5. To remove a reference, click the × on the chip.

👁️ View task detail

Click the title of a task in the list to open its detail. The screen has two columns:

ColumnContent
LeftInteractive checklist — you can check/uncheck each item by clicking.
RightGeneral information: description, assigned to, created by, due date, creation date, and list of references with links.

At the top of the detail are the Edit and Delete buttons (subject to permissions).

📊 Mark checklist progress

From the task detail, click on any checklist item to mark it as completed. The system updates in real time without reloading the page.

  1. Click the item — The checkbox turns green with a ✓ mark and the text is crossed out.
  2. The progress bar updates automatically with the new percentage.
  3. The status badge changes: Pending → In progress → Completed, based on the percentage.
  4. To uncheck an item, click it again — the system also allows reverting.
💡
When all items are checked, the status automatically changes to Completed. You don't need to change it manually.

🏷️ Statuses and priorities

Task statuses

StatusMeaningWhen assigned
PendingNo items completed yet.When the task is created, or if all items are unchecked.
In progressAt least one item completed but not all.Automatically when the first item is checked.
CompletedAll items completed.Automatically when the last item is checked.
ℹ️
If the task has no items, the status does not change automatically — you can edit it and adjust the status manually.

Priorities

PriorityWhen to use it
LowImprovement activities or those without time urgency.
MediumDefault value. Normal day-to-day activities.
HighImpacts production or has an upcoming deadline.
UrgentRequires immediate attention. Affects product quality or safety.

🔔 Automatic notifications

ZYMOS sends in-system notifications (bell in the navigation bar) in two situations:

EventWho receives itWhen
Task assigned The assigned user. When creating or editing a task, if the assignee is different from the creator. (Not notified if you assign a task to yourself.)
Task overdue The assigned user. Automatic daily check: tasks with past or today/tomorrow due dates that are not completed.
💡
Notifications appear as a red dot on the bell in the navigation bar. Click the bell to see all of them.
📱
Also via WhatsApp If the administrator has configured WhatsApp contacts in Admin → WhatsApp, task assigned events also generate a WhatsApp message to the contact subscribed to the "Task assigned" type. See Administration Manual → WhatsApp Notifications.
