Main module

Batch Traceability

Complete guide to recording, tracking and analyzing every beer batch from brewing to carbonation.

Audience: Production operators and administrators Version: Zymos 2026 App route: Side menu → Traceability

1What is Traceability?

The Traceability module is the core of Zymos. Here you record each beer batch from brew day until the product is carbonated and ready for its final destination.

A batch goes through up to 5 phases. Zymos automatically calculates which phase it is in based on the dates you register:

1
Brewing
2
Fermentation
3
Conditioning
4
Maturation
5
Carbonation

Each batch has a unique code automatically generated from the first 3 letters of the style: IPA-001, IPA-002, STO-001, etc.

Prerequisite: You must have at least one active recipe before you can create your first batch. If you don't see the "New Batch" button, go to Recipes → New Recipe first.

4Kanban view

The Kanban shows batches organised in columns by phase, like a visual board. Access it from the "Kanban" button in the side menu or from the action bar.

📌Board columns

There are 6 columns: Not started · Fermentation · Conditioning · Maturation · Carbonation · Completed

🃏Information on each card

Each card shows:

  • Batch code (e.g. IPA-004)
  • Style
  • Brew date
  • Days in current phase (number in the top-right corner)
  • Delay alert (in red) if the ideal end date has already passed

🖱️Move batches by dragging

Users with edit permission can drag a card from one column to another to change the batch's phase.

Important: To move a batch to Fermentation, it must have a fermenter assigned. If it doesn't, the system will return the card to its original position and display a message indicating that you must assign one first from the edit form.

You can also access the detail or edit each batch with the 👁 and ✏️ buttons that appear on each card.

5Create a new batch

Click + New Batch. A wizard-style form opens with 6 tabs. You don't have to complete everything at once: you can save at any time and come back to edit later.

Recommended flow: When creating the batch, complete at least Tab 0 (General Info) and Tab 1 (Recipe/Ingredients). The other tabs are filled in as the production process progresses.

The wizard tabs show a green ✓ when they have been completed, helping you know what's missing.

6Tab 0: General Info

This is the first and most important step. Here you define the fundamental parameters of the batch.

📝Required fields

FieldDescription
Style *Style name (e.g. "India Pale Ale"). Has autocomplete with registered beer types. The batch code is automatically generated from the first 3 letters.
Brew DateDay on which the main boil took place.
Start / End TimeStart and end time of session 1's boil.
Final LitresVolume obtained at the end of the process.
FermenterAssigned fermentation vessel. Only available fermenters appear (without an active batch). Required to move the batch to Fermentation in the Kanban.

📐Density measurement

Zymos supports two measurement instruments. Choose one with the Hydrometer / Refractometer toggle:

InstrumentHow to enter OGHow to enter FG
Hydrometer (SG) Enter the specific gravity directly: 1052, 1068, etc. (XXXX format, no decimal point) Same: 1012, 1008, etc.
Refractometer (°Brix) Enter the Brix degrees: 12.5, 16.2. The system calculates the equivalent SG. For FG with refractometer, the system applies the Sean Terrill correction to compensate for dissolved alcohol. The difference from the standard method is shown.

Valid ranges: OG between 1000 and 1150 · FG between 990 and 1060. The value must be entered as a whole number (without comma or point): for example, 1.052 is written as 1052.

🔁Multi-session brewing (1 to 4 sessions)

If your brewing process uses multiple boils (e.g. splitting grains from 1st and 2nd boil on different days), you can register up to 4 sessions with the "Number of sessions" selector.

When you select 2 or more sessions, additional fields appear for the date, time, OG and volume of each session. The combined OG is automatically calculated as a volume-weighted average of all sessions and written into the main OG field.

💧Other fields

  • Water used (L): total water used in session 1 (sessions 2–4 have their own field)
  • Water pH: pH measured before the boil

7Tab 1: Recipe / Ingredients

Here you record the ingredients used in this batch and optionally link them to supplier invoices to calculate costs.

📦Load from recipe

The "Load Recipe" button at the top automatically fills all ingredient fields with the quantities from the selected recipe. You can adjust the values afterwards.

When loading the recipe, the system also tries to automatically find costs in supplier invoices and pre-fills the Production Costs section.

🌾Ingredient groups

Each group allows adding multiple rows with the + button:

GroupFields per itemAvailable units
MaltsName (with inventory autocomplete), quantitygr, kg
HopsName, quantitygr, kg
YeastsName, quantitygr, kg, mL, L
Fining agentsName, quantitygr, kg, mL, L, und

If an ingredient is not yet in inventory, the ⊞ button next to the name field opens a quick form to create it without leaving the screen.

💰Production Costs

The Production Costs section lets you link specific invoice line items from suppliers to this batch. The system calculates the actual batch cost from the invoiced prices.

  • Use the search box to find invoice items by name, supplier or type
  • Indicate the quantity of that item assigned to this batch
  • If quantity = 0, the full item cost is assigned

If you have no invoices registered, you can still see an estimated cost in the detail view, calculated using unit prices from inventory.

📦Destination and Packaging

Define the formats in which the batch was packaged. Add rows with the + button. Each row indicates:

📝Observations and notes

  • Tasting notes: sensory description of the finished product

12Batch detail view

Click the 👁 View button on any batch to open the full view. Here you find all consolidated information, calculated metrics and the history.

📊Automatically calculated metrics

At the top, cards show the indicators calculated by Zymos:

MetricFormula / DescriptionWhen available
ABV (% alcohol) (OG − FG) × 0.13125. With refractometer uses the Terrill formula for greater precision. When OG and FG are registered
Apparent attenuation (OG − FG) × 100 / (OG − 1000). Indicates what percentage of sugars the yeast fermented. When OG and FG are present
Mash efficiency (OG points × litres) / (kg_malt × 308) × 100. Compares actual extraction vs maximum potential. When OG, litres and malts with quantities in kg are present
BJCP score Average of registered sensory evaluations (scale 0–50). When at least one evaluation exists

🗺️Process timeline

Below the metrics there is a visual summary of the 4 phases with their start dates. Completed steps are shown in colour; pending ones appear in grey.

📋Information sections

The detail organises all information in cards:

  • Batch information: code, style, fermenter, recipe, brew dates by session
  • Density parameters: OG (with Refractometer badge if Brix was used), FG, reading date
  • Ingredients: visual chips with each ingredient and its quantity
  • Costs: if invoice items are linked, shows the actual cost per item and the total. If no invoices exist, an estimated cost based on inventory prices may be shown.
  • Fermentation / Conditioning / Maturation / Carbonation: one section per phase with all its fields
  • Fermentation readings: history of densities and temperatures taken during the process
  • Sensory evaluation: registered BJCP evaluations
  • History: chronological record of changes to the batch

13Fermentation readings

During fermentation you can record periodic readings of density and temperature to monitor yeast activity.

Available to Administrators only. If you are an operator, you can view readings but not add or delete them.

1
Open the batch detail

Go to 👁 View on any batch with active fermentation.

2
Find the "Fermentation Readings" section

It is towards the middle of the page, with the previous readings table.

3
Click "Add reading"

Enter the date, current density and temperature. The density/temperature chart updates automatically.

Zymos automatically creates two special readings:

  • Initial OG: generated when you save the OG for the first time
  • Final FG: generated when you save the final density

These readings appear at the beginning and end of the table respectively. Manual readings are inserted in the middle.

17Duplicate a batch

The "Duplicate" button (available in the list and in the detail) creates a new copy of the batch with:

  • ✅ Same ingredients (malts, hops, yeasts, fining agents)
  • ✅ Same style and recipe
  • ❌ No dates (brew date, fermentation, etc.)
  • ❌ No densities (OG, FG)
  • ❌ No fermenter assigned
  • ❌ New code generated automatically

Useful for repeating the same beer style periodically.

If the batch destination includes kegs (e.g. "2 × 20L Keg"), Zymos can create the keg records automatically.

1
Open the batch detail

The batch must have keg-type destinations registered in Tab 5.

2

3
Confirm the creation

19AI Fermentation Diagnosis 🤖

The fermentation diagnosis analyses the batch's density and temperature curve using artificial intelligence. It detects anomalies, compares with the expected profile and suggests corrective actions.

Requirement: the batch must have at least 2 fermentation readings registered. The feature requires AI configuration (ANTHROPIC_API_KEY). If the button does not appear, the system is running without AI.

🔎How to use the diagnosis

1
Open the batch detail

Go to the Fermentation section of the detail.

2
Click "AI Diagnosis"

Button available in the Fermentation section.

3
Review the diagnosis

The modal shows: fermentation status, detected anomalies, recommendations and immediate attention warnings.

21AI BJCP Scorer 🤖

The BJCP Scorer analyses the free-text notes from the batch's sensory evaluation and suggests BJCP scores by criterion, strengths, detected flaws and improvement recommendations for the next brew.

22Email notification on phase change

ZYMOS can automatically send an email every time a batch advances to a new production phase (from Mashing to Fermentation, from Fermentation to Conditioning, etc.).

Requirement: the system must have an SMTP server configured (SMTP_HOST environment variable). If no SMTP is configured, this feature is not available. The email is sent to the tenant's email address configured in the account.

📧Email content

  • Batch name and code
  • Previous phase and new phase reached
  • Date of change
  • Direct link to the batch detail in ZYMOS

Useful in teams where different people handle each stage. The person responsible for maturation can configure their email to receive an alert when a batch enters their phase.

📱 Also via WhatsApp: If the administrator configured contacts in Admin → WhatsApp subscribed to the "Batch phase change" type, the message is also delivered via WhatsApp (or as the sole channel if no SMTP is set). See Administration Manual → WhatsApp Notifications.

23Frequently asked questions

Why doesn't the "New Batch" button appear?

You need at least one active recipe. Go to Recipes → New Recipe and create one first.

How do I know which phase a batch is in?

The phase is calculated automatically from the dates you registered: if there is a carbonation start date but no end date, the batch is in Carbonation. Zymos never asks you to manually select the phase.

I entered an incorrect density. How do I correct it?

Go to Edit the batch (Tab 0) and change the OG or FG values. Zymos will automatically recalculate ABV, attenuation and efficiency.

Can I change the fermenter once fermentation has started?

Yes. Go to Edit → Tab 0 and change the fermenter. The system will update the availability of both vessels.

What happens if I move a batch on the Kanban but it has no fermenter?

The system reverts the move and shows a notice. You must assign a fermenter first from the edit form (Tab 0).

Are final litres summed automatically in multi-session brewing?

Yes. When you register the volume of each session (S1, S2, etc.), Zymos automatically sums them in the "Final Litres" field.

Can I change the application language?

Yes. In the user menu (top-right corner of the navbar) there is a language selector: Español / English.

Where do "archived" batches go?

When a batch is archived, it is removed from the main list. The batch history remains in the system. Kegs and invoices linked to that batch are not affected.
