⚙️ Administración

Configura tu cervecería en ZYMOS: usuarios y roles personalizados, branding con los colores de tu marca, equipos de producción, barriles y toda la configuración del sistema.

Solo Administrador

Gestión de usuarios

Los usuarios son las personas que tienen acceso a tu instancia de ZYMOS. Cada usuario tiene un nombre de usuario, contraseña y un rol que determina a qué módulos puede acceder.

Accede desde Admin → Usuarios. La lista muestra todos los usuarios con su nombre, rol, estado (activo/inactivo) y fecha del último acceso.

⚠️
Auto-protección ZYMOS no te permite eliminar, desactivar ni cambiar el rol de tu propio usuario. Esto evita que puedas dejarte sin acceso al sistema accidentalmente. Estas acciones solo son posibles para los demás usuarios.

Crear un usuario nuevo

  1. Ve a Admin → Usuarios → "+ Nuevo usuario".
  2. Define el nombre de usuario (único, sin espacios) y la contraseña inicial (mínimo 6 caracteres).
  3. Selecciona el rol del usuario (ver sección Roles abajo).
  4. Guarda. El usuario puede iniciar sesión inmediatamente.
💡
Después de crear el usuario, pídele que cambie su contraseña desde su perfil (ícono de usuario en la barra superior → "Cambiar contraseña"). La contraseña inicial es temporal.

Asignar y cambiar roles

Para cambiar el rol de un usuario, edítalo y selecciona el nuevo rol. El cambio es inmediato — la próxima vez que el usuario inicie sesión tendrá los nuevos permisos (o en la sesión activa si recarga la página).

Restablecer contraseñas

Si un usuario olvida su contraseña, el administrador puede restablecerla desde la pantalla de edición del usuario. La nueva contraseña debe tener al menos 6 caracteres.

Los usuarios también pueden cambiar su propia contraseña desde su perfil, siempre que conozcan la contraseña actual.

Roles personalizados (RBAC)

Si los roles predefinidos no se ajustan a la estructura de tu cervecería, puedes crear roles completamente personalizados con permisos granulares por módulo.

  1. Ve a Admin → Roles → "+ Nuevo rol".
  2. Define el nombre del rol (ej: "Jefe de Producción", "Supervisor de Calidad").
  3. Para cada módulo, marca qué operaciones puede realizar: Ver, Crear, Editar, Eliminar.
  4. Guarda el rol. Ya puedes asignarlo a usuarios desde la pantalla de edición de cada usuario.

Branding y colores de tu cervecería

Personaliza la apariencia de ZYMOS con los colores y el logo de tu marca. Los cambios se reflejan inmediatamente en la interfaz para todos los usuarios.

Ve a Admin → Mi cervecería (o Admin → Tenants → Editar).

CampoDescripción
NombreNombre de tu cervecería. Aparece en la barra de navegación, login y documentos PDF.
TaglineSlogan corto. Aparece debajo del nombre en la pantalla de login.
Logo URLURL o ruta del logo. Si se deja vacío, ZYMOS muestra un ícono de gota por defecto. Formatos recomendados: PNG transparente, máx. 240×90px.
Color navbarColor del fondo de la barra de navegación (hex, ej: #242E0D).
Color primarioColor principal de botones, encabezados de tabla y elementos de acción.

ℹ️
Limpiar caché después de editar Si editas el branding directamente en la base de datos (sin usar el formulario de ZYMOS), haz clic en "Limpiar caché" en Admin → Tenants para que los cambios se reflejen sin reiniciar el servidor.

Unidad de temperatura

ZYMOS soporta temperaturas en Celsius (°C) o Fahrenheit (°F). La configuración afecta todos los formularios y reportes del tenant.

Cambia la unidad en Admin → Mi cervecería → campo "Unidad de temperatura".

⚠️
ZYMOS almacena siempre en Celsius internamente. Al cambiar de °C a °F (o viceversa), los datos históricos se mostrarán automáticamente convertidos — no hay pérdida de datos ni necesidad de re-ingresar valores.

Estilos de cerveza

Los estilos de cerveza (American IPA, Stout, Saison, etc.) son los tipos que aparecen en el selector del formulario de recetas. Puedes agregar, editar y desactivar estilos desde Admin → Tipos de cerveza.

ZYMOS incluye una lista base de estilos BJCP al inicializarse. Puedes agregar estilos propios o regionales según las cervezas que produces.

Mantenimientos

Programa y registra los mantenimientos preventivos y correctivos de tus equipos. Los mantenimientos próximos generan alertas en el dashboard.

  1. Ve a Admin → Equipos → selecciona un equipo → pestaña "Mantenimientos".
  2. Haz clic en "+ Registrar mantenimiento".
  3. Completa tipo (preventivo/correctivo), descripción, fecha, costo y el técnico responsable.
  4. Guarda. Si el estado del equipo es "En mantenimiento", recuerda cambiarlo a "Disponible" cuando finalice.

Plan y límites

Tu instancia de ZYMOS tiene límites según el plan contratado. Puedes ver el estado del plan en Admin → Mi plan:

  • Fecha de vencimiento: cuando vence el plan, ZYMOS muestra una página de aviso. Tienes 7 días de gracia antes de que el acceso se bloquee.
  • Límite de lotes: número máximo de lotes de producción registrados. Una alerta aparece al llegar al 90% del límite.
  • Límite de usuarios: número máximo de cuentas de usuario. Una alerta aparece al llegar al 90%.
🔴
Plan vencido Si el plan vence y pasan los 7 días de gracia sin renovar, todos los usuarios (excepto el administrador) verán una pantalla de bloqueo con instrucciones para renovar. Contacta al equipo de ZYMOS para renovar el plan.

Logs de acceso

ZYMOS registra todos los accesos al sistema. Ve a Admin → Logs de acceso para ver quién inició sesión, desde qué IP y en qué momento. Útil para auditoría de seguridad y detección de accesos no autorizados.

Importación masiva de datos

Si tienes datos existentes en Excel o en otro sistema, puedes importarlos masivamente a ZYMOS sin ingresarlos uno a uno. Ve a Admin → Importación de datos.

Módulos disponibles para importación

  • Almacén (inventario de insumos)
  • Equipos
  • Comercial (proveedores, facturas e ítems)
  • Producción (recetas, ingredientes, escalones, adiciones y lotes)
  • Clientes
  • Ventas e ítems de venta
  • Barriles
  • Órdenes de compra
  • Seguimiento de lotes
  • Catálogos (tipos de cerveza y categorías)
  • Mantenimientos de equipos
  1. Descarga la plantilla Excel del módulo que quieres importar (botón "Descargar plantilla").
  2. Llena la plantilla con tus datos. La hoja "Instrucciones" dentro del archivo explica el formato de cada columna.
  3. Sube el archivo y haz clic en "Importar".
  4. ZYMOS procesa el archivo fila por fila y muestra un resumen con las filas exitosas y los errores encontrados.
💡
Orden recomendado de importación Importa los catálogos primero (tipos de cerveza), luego el almacén y equipos, luego producción (recetas primero, lotes después). Los módulos de ventas y barriles deben importarse después de producción porque referencian los lotes por su código.
