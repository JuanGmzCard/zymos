⚙️ Administration

Configure your brewery in ZYMOS: users and custom roles, branding with your brand colors, production equipment, barrels and all system settings.

Admin only

Dashboard

The dashboard is the first screen you see after logging in. It provides an executive view of your brewery's real-time status: active batches, inventory, monthly sales, alerts and historical charts.

👋
Personalized greeting The header shows a dynamic greeting ("Good morning/afternoon/evening"), your username and the current date. It confirms you are in the right session.

Sections & metrics

The dashboard is divided into six sections, each with metrics calculated in real time from the database:

SectionMain metrics
🍺 Production BatchesTotal batches, in progress, completed, distinct styles, liters in progress (sum of final liters of active batches), overdue phases (batches past their ideal date)
📦 Inventory & EquipmentTotal ingredients, low stock, expiring soon, total equipment, under maintenance, upcoming maintenance
🔔 AlertsList of low-stock and expiring ingredients. If there are no active alerts, shows "All clear ✓"
📅 Upcoming BrewsUp to 5 future planned brews with date and recipe
📊 ChartsLiters produced last 6 months (bar chart) + distribution by style (donut). Shows explicit empty state if no data for the period.
💰 FinancesMonth's spend (invoices in current month), total historical spend, total in maintenance. Monthly sales: number of dispatched sales, revenue and unique customers (all for the current month).

Customize the dashboard

You can adjust which sections to show and in what order. Changes are saved in the browser (localStorage) and persist between sessions.

  1. Click "Customize" (top right of the dashboard).
  2. Uncheck the sections you don't want to see.
  3. Drag sections by the ⠿ handle to reorder them.
  4. To restore the original layout, use the "Reset" button in the Customize dropdown.
💡
Dashboard configuration is per browser and user, not per account. If you access from another device or browser, the dashboard will revert to its default layout.

User management

Users are the people who have access to your ZYMOS instance. Each user has a username, password and a role that determines which modules they can access.

Access from Admin → Users. The list shows all users with their username, role, status (active/inactive) and last login date.

⚠️
Self-protection ZYMOS does not allow you to delete, deactivate or change the role of your own user. This prevents you from accidentally locking yourself out of the system. These actions are only possible for other users.

Create a new user

  1. Go to Admin → Users → "+ New user".
  2. Define the username (unique, no spaces) and the initial password (minimum 6 characters).
  3. Select the user's role (see the Roles section below).
  4. Save. The user can log in immediately.
💡
After creating the user, ask them to change their password from their profile (user icon in the top bar → "Change password"). The initial password is temporary.

Assign and change roles

To change a user's role, edit them and select the new role. The change is immediate — the next time the user logs in they will have the new permissions (or in the active session if they reload the page).

Reset passwords

If a user forgets their password, the administrator can reset it from the user's edit screen. The new password must be at least 6 characters.

Users can also change their own password from their profile, as long as they know their current password.

Custom roles (RBAC)

If the predefined roles don't fit your brewery's structure, you can create fully custom roles with granular permissions per module.

  1. Go to Admin → Roles → "+ New role".
  2. Define the role name (e.g. "Head of Production", "Quality Supervisor").
  3. For each module, check which operations it can perform: View, Create, Edit, Delete.
  4. Save the role. You can now assign it to users from each user's edit screen.

Temperature unit

ZYMOS supports temperatures in Celsius (°C) or Fahrenheit (°F). The setting affects all forms and reports for the tenant.

Change the unit in Admin → My brewery → "Temperature unit" field.

⚠️
ZYMOS always stores in Celsius internally. When switching from °C to °F (or vice versa), historical data will be automatically displayed converted — there is no data loss or need to re-enter values.

Interface language

ZYMOS is available in Spanish and English. The language is persisted per user via a cookie and does not affect other users of the same tenant.

To change the language, click ES or EN in the top navigation bar (upper right corner of the side panel).

💡
User manuals are also available in English. The help button (book icon in the bar) automatically detects the active language and opens the corresponding version.

Beer styles

Beer styles (American IPA, Stout, Saison, etc.) are the types that appear in the selector of the recipe form. You can add, edit and deactivate styles from Admin → Beer types.

ZYMOS includes a base list of BJCP styles on initialization. You can add your own or regional styles according to the beers you produce.

💡
A fermenter can only be assigned to one active batch at a time. ZYMOS shows only available fermenters (without active batches assigned) in the traceability form selector.

Maintenance

Schedule and record preventive and corrective maintenance for your equipment. Upcoming maintenance generates alerts on the dashboard.

  1. Go to Admin → Equipment → select a piece of equipment → "Maintenance" tab.
  2. Click "+ Log maintenance".
  3. Fill in type (preventive/corrective), description, date, cost and responsible technician.
  4. Save. If the equipment status is "Under maintenance", remember to change it back to "Available" when done.

Plan & limits

Your ZYMOS instance has limits based on the contracted plan. You can view the plan status in Admin → My plan:

  • Expiry date: when the plan expires, ZYMOS shows a warning page. You have 7 grace days before access is blocked.
  • Batch limit: maximum number of registered production batches. An alert appears at 90% of the limit.
  • User limit: maximum number of user accounts. An alert appears at 90%.
🔴
Expired plan If the plan expires and 7 grace days pass without renewal, all users (except the administrator) will see a blocked screen with instructions to renew. Contact the ZYMOS team to renew the plan.

Access logs

ZYMOS records all system accesses. Go to Admin → Access logs to see who logged in, from which IP and when. Useful for security auditing and detecting unauthorized access.

Bulk data import

If you have existing data in Excel or another system, you can bulk-import it into ZYMOS without entering it one by one. Go to Admin → Data import.

Modules available for import

  • Warehouse (ingredient inventory)
  • Equipment
  • Commercial (suppliers, invoices and items)
  • Production (recipes, ingredients, mash steps, additions and batches)
  • Customers
  • Sales and sale items
  • Barrels
  • Purchase orders
  • Batch tracking
  • Catalogs (beer types and categories)
  • Equipment maintenance
  1. Download the Excel template for the module you want to import (button "Download template").
  2. Fill in the template with your data. The "Instructions" sheet inside the file explains the format for each column.
  3. Upload the file and click "Import".
  4. ZYMOS processes the file row by row and shows a summary with successful rows and any errors found.
💡
Recommended import order Import catalogs first (beer types), then warehouse and equipment, then production (recipes first, batches after). Sales and barrels modules should be imported after production because they reference batches by their code.

Currency & pricing format

Each tenant can configure the currency symbol that appears in invoices, sales, profitability reports and Excel and PDF exports.

  1. Go to Admin → Brewery → Edit tenant data.
  2. In the "Currency symbol" field enter your local currency symbol (e.g. $, COP, €, MXN).
  3. Save and clear the cache with the "Clear cache" button in the tenant list.
ℹ️
The currency symbol is visual only — ZYMOS does not convert values between currencies. All calculations are performed in the currency you configure.

WhatsApp notifications

ZYMOS can send automatic alerts via WhatsApp to the contacts you define. You can register multiple contacts and subscribe each one only to the alert types relevant to their role (the purchasing manager receives low-stock alerts; the brewmaster receives batch phase changes).

Access from Admin → WhatsApp.

ℹ️
Requirement: Twilio account WhatsApp notifications are sent via Twilio WhatsApp Business API. The environment variables TWILIO_ACCOUNT_SID and TWILIO_AUTH_TOKEN are required. If not configured, the system works in simulation mode: messages are logged but not sent.

Available alert types

TypeWhen it is sent
Low stockDaily review: ingredients whose stock is below the configured minimum.
ExpiryDaily review: ingredients expiring in the next 30 days.
Batch phase changeImmediately when a batch advances to the next phase (e.g. from Brew day to Fermentation).
Pending maintenanceDaily review: equipment in "Under maintenance" status.
GMP health alertImmediately when an employee reports symptoms and requires admin authorization.
Task assignedImmediately when a task is created or edited with an assigned user.
Plan expiringDaily review: when the plan is expired or about to expire.
Monthly summaryOn the first day of each month with the previous month's production summary.

Add a WhatsApp contact

  1. Go to Admin → WhatsApp → "+ New contact".
  2. Enter the contact's name and phone number in E.164 format (with country code, e.g. +13001234567).
  3. Check the boxes for the alert types you want to subscribe this contact to. You can select one or multiple types.
  4. Save. The contact will appear in the list with active subscriptions.
💡
The number must have accepted Twilio messages In the Twilio sandbox (test environment), the recipient must first send the message join <sandbox-keyword> to the Twilio number before they can receive messages. In production with a verified number this is not necessary.

Manage existing contacts

  • Activate / deactivate: use the toggle button in the list to temporarily suspend notifications to a contact without deleting it.
  • Edit subscriptions: click "Edit" to change the contact's number or subscriptions.
  • Delete: permanently deletes the contact and all their subscriptions.
⚠️
If the banner "Simulation mode active" appears in the contact list, it means the Twilio credentials are not configured. Messages are logged in the server log but do not reach WhatsApp.

Demo tenant

If your system includes a demo tenant (demo), you can reset it from the tenant list. The demo tenant allows potential customers to explore the system with realistic data without affecting your real production.

Reset the demo tenant

  1. Go to Admin → Tenants.
  2. Find the demo tenant in the list.
  3. Click the "Reset Demo" button.
  4. ZYMOS deletes all demo tenant data and re-seeds it with a realistic dataset: batches at different phases, ingredients, suppliers, customers and a sample sale. The demo / demo user is automatically restored.
⚠️
The reset deletes all current data in the demo tenant. This operation cannot be undone. It does not affect any other tenant.

Plans & self-service payments

ZYMOS includes a checkout system that allows new customers to subscribe to a plan and self-provision without manual intervention from the sales team.

Available plans

PlanIncluded modules
MashTraceability, Recipes, Inventory, Equipment, GMP, AI Chat
BoilEverything in Mash + Commercial (invoices, sales, PO), Barrels, Reports, Tasks
FermentationEverything in Boil + Custom RBAC roles, Bulk import

Checkout flow for new customers

  1. The new customer visits /planes and selects their plan.
  2. They fill in their brewery name and email. ZYMOS automatically generates a unique subdomain (e.g. mybrewery.zymos.app).
  3. They are redirected to the payment gateway (MercadoPago). Once payment is approved, ZYMOS creates the tenant, roles, default beer styles and sends a welcome email with login credentials.
  4. The new tenant can log in immediately at their subdomain.
ℹ️
If the system does not have a MercadoPago token configured (MP_ACCESS_TOKEN), the checkout works in simulation mode: payment is automatically approved for testing. Useful in development and demo environments.
