What is Zymos?

Zymos is a comprehensive management platform designed exclusively for craft breweries. It centralizes all business processes in one place: production, inventory, equipment, food safety, sales, billing, and analytics.

Craft breweries simultaneously manage technical recipes, batches in different fermentation stages, perishable ingredients, equipment requiring maintenance, customers, and suppliers — often using spreadsheets and scattered tools that don't communicate with each other. Zymos solves this problem with a unified platform, accessible from any browser with no software installation required.

As a multi-tenant SaaS platform, each brewery operates in its own isolated environment with its own branding, colors, and private data — while sharing the same robust infrastructure that is updated automatically.

Market Problem & Opportunity

The craft beer industry is steadily growing in Latin America and worldwide, but its operators lack specialized digital tools to manage their business professionally.

Craft breweries mostly operate with spreadsheets, physical notebooks, or generic tools that don't reflect the particularities of the brewing process or comply with current food safety regulations.

  • 📋
    Fragmented traceability Each process phase (mashing, boiling, fermentation, conditioning, carbonation) is recorded in disconnected systems or on paper, making quality analysis and food safety traceability impossible during an audit.
  • 💸
    No cost control Without integration between supplier invoices, ingredients, and produced batches, breweries don't know their real cost per liter nor can they identify which recipes or styles are most profitable.
  • 🛡️
    Manual regulatory compliance Good Manufacturing Practices (GMP) required by food regulations — health status, pest control, cleaning — are documented on paper, creating legal risk and wasted time during audits.
  • 🔀
    Fragmented commercial management Quotes, sales, purchase orders, and supplier management operate in separate systems without unified visibility into the business's real financial status.

The opportunity

Colombia: ~400 registered craft breweries  ·  Latin America: ~3,000 breweries  ·  Global craft brewing software market: >USD 300M/year · growing 8–12% annually

Zymos enters this market with a specialized product in Spanish, English, and Portuguese, adapted to local regulations and preferences, with a low-entry-cost SaaS model for the end customer.

Security & Access Control

Zymos implements a layered security model covering authentication, granular authorization, data isolation, and food safety compliance:

🏷️
Dynamic RBAC per tenant Each brewery defines its own roles with granular permissions per module (View / Create / Edit / Delete). 5 system roles + unlimited custom roles.
🔑
Robust authentication BCrypt passwords, automatic lockout on configurable failed attempts (attempts and duration in minutes).
🛡️
CSP enforced Active Content Security Policy. No inline scripts. Dynamic nonces in all code blocks on every page.
🍪
Secure and persistent sessions Sessions stored in PostgreSQL (survive restarts). HttpOnly + Secure + SameSite=Strict cookies in production. Concurrent session limit per user.
🏢
Multi-tenant isolation Hibernate @TenantId filter on all entities. Impossible to access another tenant's data even with direct queries or valid tokens.
🏥
GMP health control The system verifies the daily health log of each operator and blocks access if there are symptoms pending administrator authorization.
⚡
JWT API + Rate Limiting HS256 tokens with configurable TTL. 100 req/min per IP limit with HTTP 429 response. SpringDoc OpenAPI for automatic documentation.
📝
Access auditing Every login recorded in the database in an independent transaction — persists even if the session fails or rolls back. Multi-tenant error tracking with Sentry.

Plan limits and automatic renewal

Alerts at 90% and 100% of batch and user usage · 7-day grace period lockout post-expiry
Tenant and plan management from the super-administrator panel

Multi-Tenant SaaS Architecture

Zymos operates as a shared platform where each brewery is an independent tenant with complete data isolation:

🌐

Own subdomain

Each client accesses via
mybrewery.zymos.app

🔒

Isolated data

@TenantId filter on all entities — no cross-tenant mixing possible

🎨

Custom branding

Logo, colors and fonts configurable per client

⚡

Updates

Improvements deployed to all clients simultaneously

This architecture allows scaling the number of clients without a proportional increase in operational costs, while maintaining security and performance for all.

Key Differentiators

1
True multi-tenant — no instance silos A single deployment serves N breweries with complete data isolation, own branding, and independent roles per client. No infrastructure multiplication for each new client.
2
GMP embedded in the daily operational flow The food safety module is not an external add-on. The system actively blocks access for operators with pending health symptoms — requiring the administrator's digital signature to authorize the exception.
3
Granular RBAC configured by the brewery Roles are not fixed by the system. Each client creates, names and configures them with permissions per module (View / Create / Edit / Delete). An operator sees exactly and only what they need.
4
Accelerated onboarding from existing data The XLSX migrator imports the full history — recipes, batches, suppliers, invoices, customers, equipment — in minutes from the brewery's current spreadsheets.
5
Complete financial traceability per batch From the supplier invoice to cost per liter produced. Includes automatic estimated cost based on inventory prices when no invoices are assigned.
6
Enterprise code quality with 1,025 tests SpotBugs static analysis in CI, 96 migrations without regression, exhaustive technical documentation. The code is maintainable, extensible and continuously audited.
7
Artificial Intelligence integrated into the operational flow 7 AI services with Claude API: generates recipes, pre-fills invoices from photos (Vision), diagnoses fermentations, produces commercial copy, scores beers with BJCP and analyzes profitability. Works in mock mode without API key — ideal for cost-free demos.
8
Complete conversion funnel — from visitor to operating client Public landing page → one-click demo (auto-login, no password) → self-checkout with MercadoPago or Stripe → tenant provisioned automatically → onboarding emails on days 1/3/7 → reminder before trial expiry. All without operational team intervention.
9
True multi-language — ES, EN and PT-BR from day one Three exactly synchronized i18n bundles. Templates, PDFs, emails, landing, checkout and manuals available in Spanish, English and Portuguese. Language selector on every page, persists in a per-user cookie.
